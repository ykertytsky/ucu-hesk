This codebase is fork of existing project hesk.com - HESK is a PHP based help desk software that allows you to manage customer support tickets. It provides a user-friendly interface for both customers and support agents, making it easier to track and resolve issues efficiently. The software includes features such as ticket management, knowledge base, email notifications, and reporting tools to help businesses provide excellent customer service.
We don't take any credit for the original code, we just want to make it more accessible and easier to use for everyone. We will be adding new features and improvements to the codebase, so stay tuned for updates!
